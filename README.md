# ANR Florist 🌸

// ANR Florist is a mobile app made to make buying and managing flowers easier.
//
// Customers can browse different flowers, add them to their cart,
// place orders, check their order history, and manage their wishlist.
//
// Staff and admins can manage the products, keep track of inventory,
// handle orders, and view reports.
//
// The app was built using React Native, Expo, JavaScript, and Supabase.
//
// This project is still being developed, so more features and improvements
// may be added in the future.
